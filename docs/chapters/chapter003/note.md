## Notes

- 컨트롤러: 웹 MVC의 컨트롤러 역할
- 서비스: 핵심 비즈니스 로직 구현
- 리포지토리: 데이터베이스에 접근, 도메인 객체를 DB에 저장하고 관리
- 도메인: 비즈니스 도메인 객체
- optional 객체는 뭐지
- Map은 인터페이스고 실제 클래스는 HashMap이나 TreeMap
- long 타입을 정수에 실제로 넣고 싶으면 L을 붙여야 함
- Map.values() 는 collection으로 값을 꺼냅니다.
- Collection.stream()이면 값을 하나씩 흘려보내며 모두 처리합니다. 순회와 유사합니다.
- object.filter(x -> x에 관한 함수) 여기서 filter 내에 boolean 값을 내는 함수를 지정하여 필터링을 합니다.
