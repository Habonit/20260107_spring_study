## Notes

- 웹에선 정적 컨텐츠 전달, MVC와 템플릿 엔진, API 이렇게 3가지로 개발을 분류할 수 있다.
- 컨트롤러보다 정적 파일보다 우선순위가 높다. 만약에 요청 경로에 해당하는 컨트롤러가 없다면 정적 파일로 요청을 보내게 된다.
  - 타임리프와 같은 템플릿 엔진도 결국 데이터를 받아 이걸 html로 뿌리는 것이다.
- static nested class: 외부 클래스 인스턴스 없이 독립적으로 생성 가능
- inner class (non-static): 외부 클래스 인스턴스가 있어야만 생성 가능
- @ResponseBody가 없다면, 그리고 정적 컨텐츠가 아니라면, 맞는 템플릿 엔진을 찾아서 렌더링을 해서 내려준다.
  - 있다면 객체는 Json으로 아니면 String으로 내린다.
